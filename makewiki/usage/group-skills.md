# Group skills

Group skills make a published global skill available to members without copying it into every
account. A group owner or administrator controls which skills are enabled.

## Enable a skill

1. Open **Group Skills** or the group's skill catalog.
2. Select a group you manage.
3. Choose a published global skill.
4. Select a version policy:
   - **Latest:** follows the latest eligible published version.
   - **Locked:** stays on a selected version.
5. Enable it and confirm members can see it.

Only global skills granted to the group and in a usable published state can be enabled.

## Change policy or disable

Group owners and administrators can switch the policy, change a locked version, or disable the
skill. A member may consume enabled content but cannot change the grant.

Use **Latest** when central updates should flow automatically. Use **Locked** for regulated,
tested, or change-sensitive workflows where the group needs an explicit upgrade decision.

## When a skill disappears

A skill may stop being available when the platform administrator disables/archives it, removes
the group's grant, or when the chosen version is no longer eligible. Ask the group manager to
check the grant and the platform administrator to check global publication state.
