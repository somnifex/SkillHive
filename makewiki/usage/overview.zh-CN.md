# 使用 SkillHive

主导航按内容归属和使用范围组织：

- **仪表盘：**汇总自己的 Skill、群组和最近内容。
- **我的 Skill：**保存当前账号拥有的私有内容。
- **模板：**包含个人模板以及你有权使用的群组/全局模板。
- **群组：**处理成员关系和群组管理。
- **群组 Skill：**展示群组已启用的全局 Skill。
- **平台管理：**只对平台管理员显示。
- **设置：**提供账号操作和仅保存在当前设备上的明暗主题。

## 理解模板与 Skill

**模板**是可重复使用的起步结构。从模板实例化后，会创建一个新的私有 **Skill**，其中
包括生成的 `SKILL.md` 内容和来源模板标识。**全局 Skill** 是另一套流程：先由平台管理员
发布，再由群组管理者为成员启用。

私有 Skill 和全局 Skill 的修改会产生不可变版本记录。能够访问当前 Skill 不代表可以
读取其他用户的私有内容。
