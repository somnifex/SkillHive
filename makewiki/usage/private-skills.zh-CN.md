# 私有 Skill

私有 Skill 只属于一个账号。查询、读取、修改、复制和删除都会限定所有者；即使调用者是
平台管理员，也不能绕过该隔离读取正文。

## 创建 Skill

打开“我的 Skill”并新建。填写易读名称、当前账号内唯一的标识、可选描述和 Skill 内容；
也可以[从模板创建](templates.zh-CN.md)。

首次保存会生成一个不可变的初始版本，并把它设为当前版本。

## 查找与编辑

可以使用搜索、筛选和分页定位 Skill。保存内容变更时会创建新版本，不会覆盖旧版本，因此
版本记录能够展示内容演变。

如果界面要求填写版本说明，建议写清本次变化，以便后续审阅和判断；历史版本记录本身不可
修改。

## 复制

复制会在当前账号下创建另一个私有 Skill。使用不同标识后，可以独立修改，不影响来源。

## 删除

删除采用软删除：内容会从普通列表消失，但底层记录不会立即擦除。当前界面没有自助恢复
操作，删除前应确认。

## 使用生成的 Markdown

从模板创建的 Skill 会包含 `SKILL.md` 风格 Markdown 和来源模板信息。目前尚无一键下载
完整 Skill 包的功能；外部工具需要文件时，请把内容复制到目标 Skill 目录。
