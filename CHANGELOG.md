## [0.1.0] - 2026-07-30

### Added

- Account registration, token-based login, refresh-session rotation, logout, password changes,

  and login-failure lockout.
- Private skill creation, editing, copying, version history, search, pagination, and soft deletion.
- Personal, group, and global templates with permission-aware management.
- An OpenAI-style starter template for every user and template-to-skill creation.
- Group membership, invitations, join approval, roles, ownership transfer, and dissolution.
- Versioned global skills with publish, disable, archive, group grant, latest, and locked policies.
- Platform administration for users, groups, global skills, grants, and audit logs.
- React browser interface with light and dark themes.
- SQLite defaults plus PostgreSQL and MySQL compatibility.
- Alembic migrations, idempotent demo seed data, Docker images, Compose, and local PowerShell

  workflows.
- Backend, frontend, integration, type, lint, migration, and production-build checks.
- SkillHive visual identity, bilingual user documentation, and open-source community files.
