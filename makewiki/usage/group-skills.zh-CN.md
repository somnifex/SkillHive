# 群组 Skill

群组 Skill 让成员直接使用已发布的全局 Skill，无需为每个账号复制一份。由群组所有者或
管理员决定启用哪些内容。

## 启用 Skill

1. 打开“群组 Skill”或群组的 Skill 目录。
2. 选择自己管理的群组。
3. 选择一个已发布的全局 Skill。
4. 选择版本策略：
   - **最新：**自动跟随符合条件的最新已发布版本。
   - **锁定：**保持在指定版本。
5. 启用后，确认普通成员可以查看。

只有已授权给该群组、且处于可用发布状态的全局 Skill 才能启用。

## 调整策略或停用

群组所有者和管理员可以切换策略、更换锁定版本或停用；普通成员可以使用已启用内容，但
不能修改授权。

希望中央更新自动生效时使用“最新”；受监管、已验证或对变更敏感的流程适合“锁定”，由
群组明确决定何时升级。

## Skill 突然不可用

平台管理员停用/归档 Skill、移除群组授权，或选定版本不再符合条件时，内容可能消失。
可先请群组管理者检查授权，再请平台管理员检查全局发布状态。
