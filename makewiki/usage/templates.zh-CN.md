# 模板

模板用于提供一致的起步说明，同时把“谁能维护模板”和“谁能使用模板”分开控制。

## 范围与权限

| 范围 | 谁能创建或管理？  | 谁能使用？ |
| -- | --------- | ----- |
| 个人 | 模板所有者     | 模板所有者 |
| 群组 | 群组所有者或管理员 | 该群组成员 |
| 全局 | 平台管理员     | 已登录用户 |

平台管理员不能利用管理权限读取其他用户的个人模板正文。

## 默认起步模板

每个账号都会得到一个 OpenAI 风格的个人起步模板。已有安装会通过迁移/初始化逻辑补齐
缺失模板，这个过程可安全重复执行。

默认模板鼓励使用带前置元数据和清晰任务说明的 `SKILL.md`。如果工作流需要不同结构，可以
修改副本或另建模板。

## 创建模板

1. 打开“模板”，选择新建。
2. 选择自己有权管理的范围。
3. 创建群组模板时，选择自己担任所有者或管理员的群组。
4. 填写可复用名称、描述、正文和 Manifest 默认值。
5. 保存，并确认目标用户可以看到。

修改或删除群组/全局模板需要相同的管理角色。已经从模板创建的 Skill 是独立记录，不会
随着模板删除而消失。

## 从模板创建 Skill

1. 找到一个当前可见的模板。
2. 选择从模板创建操作。
3. 填写新 Skill 的名称和唯一标识。
4. 检查生成的正文和 Manifest。
5. 保存。

结果始终是操作人的私有 Skill；使用群组或全局模板并不会让生成的 Skill 自动共享。
