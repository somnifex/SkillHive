# 平台管理

只有平台管理员可以进入“平台管理”。这里治理共享平台状态，但不会提供读取私有 Skill 或
个人模板正文的后门。

## 用户与群组

管理员可以列出用户、修改账号状态、查看全部群组及其成员、调整成员角色和群组状态。需要
阻止访问时使用暂停状态，同时保留审计和调查所需记录。

群组所有权和角色调整会改变共享资源管理能力，提交前应再次确认目标用户和群组。

## 全局 Skill

1. 创建草稿。
2. 增加一个不可变版本。
3. 审查正文与元数据。
4. 发布目标版本。
5. 授权给指定群组。

已发布 Skill 可以停用或归档。这些状态变化可能影响所有正在使用它的群组，尤其是采用
“最新版本”策略的群组。

## 全局模板

平台管理员维护所有已登录用户可见的模板。用户从全局模板创建出的 Skill 仍然只属于自己。

## 审计日志

审计记录涵盖认证、账号、群组、Skill、模板和授权操作。可使用筛选与分页调查变更。导出
或截取审计信息时要按敏感数据处理，其中可能包含身份和运行元数据。

## 管理习惯

日常私有工作应使用普通账号，只在治理时使用管理员账号。共享访问前，必须把管理员密码从
示例值更换为独立强密码。
