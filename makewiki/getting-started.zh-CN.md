# 快速入门

本指南从首次启动 SQLite 版 SkillHive 开始，带你创建一个带版本记录的私有 Skill。

## 1. 安装并启动

先完成[本地安装](installation.zh-CN.md)，再运行：

```powershell
.\scripts\dev.ps1
```

浏览器访问 <http://127.0.0.1:5173>；API 文档位于 <http://127.0.0.1:8000/docs>。

## 2. 登录

仅在独立的本机体验环境中，可以使用 `admin` / `Admin123!`，也可以自行注册。示例账号属于
公开开发数据，不能继续用于共享环境。

注册要求：

- 用户名 3–50 位，只能包含字母、数字、`_`、`.`、`-`；
- 使用有效邮箱地址；
- 密码 8–128 位，并同时包含大写字母、小写字母和数字。

每个新账号都会自动获得一个符合推荐 `SKILL.md` 结构的个人起步模板。

## 3. 从默认模板创建 Skill

1. 打开“模板”。
2. 找到自己的 OpenAI 起步模板。
3. 选择从模板创建 Skill。
4. 填写唯一标识并修改生成的内容。
5. 保存后，这个 Skill 只对你的账号可见。

模板范围和权限见[模板](usage/templates.zh-CN.md)，编辑与版本记录见
[私有 Skill](usage/private-skills.zh-CN.md)。

## 4. 创建群组

打开“群组”并选择加入策略。作为所有者，你可以邀请成员、审批申请、创建群组模板并启用
已发布的全局 Skill。数据模型虽然预留了邀请链接类型，但当前尚未提供邀请链接流程。

## 5. 停止服务

关闭前后端终端进程即可。若使用 Docker Compose：

```powershell
docker compose down
```

本地 SQLite 数据仍保存在 `data/skillhive.db`。
