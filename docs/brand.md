# SkillHive 品牌与 Logo

SkillHive 标志由六边形蜂巢、连接节点和抽象的 `S` 形路径组成，表达“把分散的能力组织成
可复用、可协作的团队资产”。整体保持专业、克制，在浅色与深色界面中都具有辨识度。

## 资产

| 文件                                                | 用途                                |
| ------------------------------------------------- | --------------------------------- |
| `frontend/public/brand/skillhive-logo.png`        | 网站、README 和常规界面使用的 512 px 透明 Logo |
| `frontend/public/brand/skillhive-logo-master.png` | 高分辨率透明母版                          |
| `frontend/public/brand/favicon-16.png`            | 浏览器 16 px 图标                      |
| `frontend/public/brand/favicon-32.png`            | 浏览器 32 px 图标                      |
| `frontend/public/brand/apple-touch-icon.png`      | Apple 主屏幕图标                       |

## 色彩

- 深松绿：`#32483F`
- 鼠尾草绿：`#4F6F62`
- 蜂蜜金：`#E6A84B`
- 暖白背景：`#F7F7F5`

## 使用约定

- 常规界面中不要小于 24 px。
- 保持原始比例，并在四周保留至少标志宽度 10% 的留白。
- 不旋转、不拉伸、不重新着色，也不要添加描边、文字或复杂阴影。
- 优先使用透明版本；需要不透明触控图标时使用现成的 Apple 图标文件。
