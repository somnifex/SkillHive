# Using SkillHive

The main navigation organizes work by ownership and audience:

- **Dashboard** summarizes your skills, groups, and recent activity.
- **My Skills** contains content owned by your account.
- **Templates** contains personal templates plus group/global templates you may use.
- **Groups** handles membership and group administration.
- **Group Skills** shows published global skills available through your groups.
- **Administration** appears only to platform administrators.
- **Settings** contains account actions and the device-local light/dark theme.

## A useful mental model

A **template** is a reusable starting structure. Instantiating it creates a new private **skill**,
including generated `SKILL.md` content and a reference to the source template. A **global skill**
is different: a platform administrator publishes it, then a group manager enables it for members.

Changes to private and global skills create immutable version records. Access to a current skill
does not grant access to another user's private content.
